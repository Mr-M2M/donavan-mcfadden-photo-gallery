# Donavan McFadden - Photo Gallery

SDC340 Mobile App Development (ECPI) — Performance Assessment: Personal Photo Gallery App.
Branded with the Marchers Only ("You Are Meant For More") identity.

## Structure
- `MainActivity` — splash screen (name + "My Photo Gallery")
- `GalleryActivity` — main screen, 6 thumbnail images in a grid
- `ImageDetailActivity` — enlarged view shown after tapping a thumbnail

## How to run
1. Open this folder in Android Studio (Jellyfish or newer).
2. Let Gradle sync.
3. Run on an emulator (API 24+).
4. Capture the required screenshots (Design view, Text view, .kt files, and the
   3 running-app screens) directly from your machine so the system clock in
   each screenshot is genuinely yours, per the assessment's screenshot requirement.
